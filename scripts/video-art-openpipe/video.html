05 · O coração do ART

O loop de treino

1
Inferência: vários rolloutsEm paralelo. Cada conversa vira uma Trajectory.
2
RecompensaSua função de nota, ou o RULER.
3
Treino com GRPOGrupos vão pro backend. A inferência pausa.
4
Checkpoint novoLoRA salvo e carregado no vLLM. Recomeça.
06 · GRPO sem medo

Nota relativa ao grupo

vantagem (advantage)
vantagem = nota − média do grupo

Todas tiraram 0,7?
Vantagem = 0 → o ART descarta. Nada a aprender.

src/art/preprocessing/tokenize.pyreward_mean = sum(t.reward for t in group) / len(group)for trajectory in group: advantage = trajectory.reward - reward_mean if scale_rewards: advantage /= reward_std + 1e-6 if advantage == 0 and drop_zero_advantage_trajectories: continue

08 · Na prática

O código cabe numa tela

import artfrom art.serverless.backend import ServerlessBackendfrom art.rewards import ruler_score_group model = art.TrainableModel(name="agente-001", project="meu-agente", base_model="Qwen/Qwen3.8-27B")backend = ServerlessBackend() # ou LocalBackend(), se tiver GPUawait model.register(backend) async def rollout(model, cenario) -> art.Trajectory: traj = art.Trajectory(messages_and_choices=[...]) # system + user resp = await model.openai_client().chat.completions.create( model=model.get_inference_name(), messages=traj.messages()) traj.messages_and_choices.append(resp.choices[0]) return traj # a nota vem do RULER for passo in range(await model.get_step(), 50): grupos = await art.gather_trajectory_groups( (art.TrajectoryGroup(rollout(model, c) for _ in range(8)) for c in cenarios), after_each=lambda g: ruler_score_group(g, "openai/o4-mini")) result = await backend.train(model, grupos, learning_rate=1e-5) await model.log(grupos, metrics=result.metrics, step=result.step, split="train")
1 · Modelo + backendTrainableModel e register()
2 · rollout()roda o agente num cenário e devolve uma Trajectory
3 · Grupos de 8 + RULERgather_trajectory_groups + ruler_score_group
4 · backend.train()um passo de GRPO; repete e acompanha a nota
